# One keyword per line. Lines starting with # are ignored.
#
# Drives `python -m app.youtube collect --keywords keywords.txt`, and is
# the same list to search by hand on TikTok and Douyin, so the three
# platforms stay comparable.
#
# A video found by several keywords is one observation, recorded with
# all of them, so a per-keyword count does not depend on this order.
#
# Measured on the first 150 YouTube results, with
# `app.relevance --by-keyword`:
#
#   拉拉        30 found, 17 in scope (57%)
#   女同        12 found,  4 in scope (33%)
#   女同志       9 found,  2 in scope (22%)
#   女同性恋   110 found,  3 in scope (3%) -- 105 of them not in Chinese
#
# The counter-intuitive result, and the reason this file has comments:
# the most precise Chinese term leaks into other languages the most.
# 女同性恋 is a clean translation of "lesbian", so the search maps it
# across languages and returns English and Spanish results. 拉拉 and
# 女同 are community slang with no such mapping, so they stay Chinese.
#
# Everything is kept anyway. Off-topic rows are marked, not deleted
# (app/relevance.py), and quota is not the binding constraint at this
# volume -- three keywords over 72 hours cost 704 of 10,000 daily
# units. Precision is cheap; a term dropped is recall that cannot be
# recovered later, because the videos will be gone.
