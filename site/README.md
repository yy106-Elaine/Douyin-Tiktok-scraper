# A page about the researcher and the study

**It is not recruitment material, and it must not become any.**

Recruitment is Attachment 1 of protocol #27037R — an approved text,
sent as written (`docs/OUTREACH.md`). This page is background for
somebody who wants to know who is asking before they answer: who she
is, what the study is, who supervises it, where to complain.

That distinction is why the ¥50, the interview length and the
"looking for interviewees" card came off this page. Offering
compensation in an unapproved place, in a protocol whose first stage
deliberately offers none, is a protocol deviation written in HTML.

**The approved recruitment message does not link here**, and adding
a URL to it would be a change to study materials. Until the HRPP has
been asked, the page stands on its own — reachable from the account
bio, which is itself approved text — and the DM goes out exactly as
written.

## Fill in

Nothing. Email, IRB protocol and GitHub username are in.

## Put it online (about five minutes)

GitHub Pages, from a repository of its own so this study's code
stays private:

```bash
# 1. Make an empty public repo on github.com named  <username>.github.io
# 2. Then, from this folder:
cd site
git init
git add index.html
git commit -m "Researcher page"
git branch -M main
git remote add origin https://github.com/<username>/<username>.github.io.git
git push -u origin main
```

Live at `https://<username>.github.io` within a minute or two. Check
it on a phone before sending anything — that is where it will be
read.

## What is deliberately left off, and why

The CV has more on it than this page does. What is here was chosen
for one reader: somebody in a queer community in China deciding
whether a stranger asking about their posts is safe to answer.

**Left off: the Citi sales-and-trading internship, the fintech data
analyst role, "open to work".** They are real and they are good, and
to this reader they say *corporate person collecting data*, which is
the exact doubt the page exists to answer. The research roles do the
opposite: a named college, named advisors, a named thesis, and prior
interview work with Chinese respondents.

**Kept, deliberately: the Yale interview work.** "Has done this kind
of interview before, with people like me" is the single most
reassuring fact available.

**The thesis is described without leading on 审查.** Not to soften it
— the study is about posts coming down and the page says so — but
because a page that opens with the word is read as political before
it is read as research. The English title on LinkedIn stays as it is.

## What is deliberately not on it

- **No photo.** Optional, and a judgement only she can make: it adds
  credibility and it attaches a face to a public page about queer
  research.
- **No claim about what this study has found.** The page is read by
  people who have not consented to anything yet, and some of them may
  be in the corpus.
- **Nothing about any individual account**, ever.
