# The page the recruiting message points at

Without it, the first DM is an anonymous stranger asking a queer
creator to talk about censorship. The link is what makes it a study.

## Fill in five things

Open `index.html`, find the `ME = { … }` block near the top, replace
the five values. Nothing else needs touching.

Until they are replaced the page shows a yellow warning naming what
is still missing — **do not send the link to anyone while that
warning is there.** A page still carrying `YOUR NAME` is worse for
credibility than no page at all.

## Put it online (about five minutes)

GitHub Pages, from a repository of its own so this study's code
stays private:

```bash
# 1. Make an empty public repo on github.com named  <username>.github.io
# 2. Then, from this folder:
cd site
git init
git add index.html
git commit -m "Researcher page"
git branch -M main
git remote add origin https://github.com/<username>/<username>.github.io.git
git push -u origin main
```

Live at `https://<username>.github.io` within a minute or two. Check
it on a phone before sending anything — that is where it will be
read.

## What is deliberately not on it

- **No photo.** Optional, and a judgement only she can make: it adds
  credibility and it attaches a face to a public page about queer
  research.
- **No claim about what this study has found.** The page is read by
  people who have not consented to anything yet, and some of them may
  be in the corpus.
- **Nothing about any individual account**, ever.
